## 📦 Official NPM Libraries

Sebagai bentuk kontribusi aktif pada ekosistem JavaScript Global, saya membangun dan merilis beberapa *library* publik:

- 💳 **[web3-direct-pay](https://www.npmjs.com/package/web3-direct-pay):** Sistem *Payment Gateway* kripto desentralisasi (USDT & BNB) dengan 0% biaya platform dan tanpa *gas fee* untuk *merchant*.
- 🤖 **[express-ai-router](https://www.npmjs.com/package/express-ai-router):** Middleware ajaib untuk Express.js yang secara instan menyulap rute statis menjadi *Mock API* bertenaga AI (Google Gemini).
- 🕵️ **[mern-ai-auditor](https://www.npmjs.com/package/mern-ai-auditor):** Alat CLI Global untuk mengaudit keamanan dan kualitas kode pada proyek ekosistem MERN (*MongoDB, Express, React, Node.js*) menggunakan kekuatan AI.
- 📱 **[adaptui-core](https://www.npmjs.com/package/adaptui-core) & [adaptui-cli](https://www.npmjs.com/package/adaptui-cli):** Framework Web Components yang adaptif dengan OS pengguna, dilengkapi dengan CLI Builder untuk membungkus kode web menjadi Native Android App (Capacitor) dalam satu klik.
